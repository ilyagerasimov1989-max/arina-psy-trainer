# Тренажёр Арины — медицинская психология

Авторский статический тренажёр для подготовки к первичной специализированной аккредитации медицинского психолога.

## Как пользоваться

- «Полный круг» — пройти все 120 вопросов.
- «Круг ошибок» — повторить только вопросы, на которые ещё не отвечено правильно.
- «Экзамен» — случайная выборка вопросов.
- «Материалы» и «Прогресс» — конспект и статистика.

После ошибки сразу показываются объяснение и ассоциация. Правильный ответ удаляет вопрос из активных ошибок.

Это авторский учебный материал, а не официальный банк аккредитации и не копия «Медиктеста».

Прогресс, ошибки и история хранятся в localStorage отдельно в каждом браузере и на каждом устройстве (Android, Windows, iPhone, Mac).
